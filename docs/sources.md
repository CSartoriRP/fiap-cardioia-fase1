# Fontes de Dados — CardioIA Fase 1

## 1. Dataset Numérico

O dataset numérico é **simulado**, gerado para fins acadêmicos, com 200 registros fictícios. Não representa indivíduos reais e não possui validade clínica.

## 2. Dados Textuais

Os arquivos são sínteses educacionais elaboradas para o projeto, e não reproduções integrais das fontes.

### Doenças Cardiovasculares

**Fonte:** World Health Organization (WHO)  
**URL:** https://www.who.int/news-room/fact-sheets/detail/cardiovascular-diseases-(cvds)  
**Arquivo:** `cardiovascular_diseases_who.txt`

### Eletrocardiograma

**Fonte:** MedlinePlus — U.S. National Library of Medicine  
**URL:** https://medlineplus.gov/lab-tests/electrocardiogram/  
**Arquivo:** `electrocardiogram_medlineplus.txt`

## 3. Dataset Visual

**Fonte:** Mendeley Data  
**Dataset:** ECG Images dataset of Cardiac Patients  
**URL:** https://data.mendeley.com/datasets/gwbz3fsgp8/2  
**Licença informada pela fonte:** CC BY 4.0

Foram selecionadas 100 imagens JPG: 25 Abnormal Heartbeat, 25 History of MI, 25 Myocardial Infarction e 25 Normal.

**Conjunto preparado no Google Drive:**  
https://drive.google.com/file/d/1U3q3aBCRKs19cd5Xl6TDOn4l43gjKi3n/view?usp=sharing

## 4. Governança e Uso

O projeto combina dados numéricos simulados, textos derivados de fontes institucionais e imagens de dataset acadêmico público. Nenhuma informação pessoal identificável foi adicionada ao dataset numérico. Todo o conteúdo possui finalidade acadêmica e experimental no contexto do CardioIA.
